# Checklist do Gate de Arquitetura (Architecture Gate)

Critérios obrigatórios para aprovação da fundação técnica:

- [ ] Definição de limites de contexto e diagrama de componentes
- [ ] Contratos de API especificados com métodos HTTP, rotas, payloads de entrada e respostas
- [ ] Modelagem de banco de dados relacional/documental com chaves primárias e relacionamentos
- [ ] Governança de segurança documentada (autenticação, permissões, criptografia)
- [ ] Fluxo de dados com tratamento de idempotência e tolerância a falhas
- [ ] Especificação de observabilidade (logs estruturados, métricas e tracing)
