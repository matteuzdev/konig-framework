# Checklist do Gate de Qualidade de Código (Code Quality Gate)

Critérios obrigatórios para aceitação de código de engenharia:

- [ ] Ausência total de placeholders inacabados (sem TODOs, sem 'pass', sem mocks vazios)
- [ ] Tipagem estrita em parâmetros e retornos de funções
- [ ] Tratamento explícito de exceções nas bordas com mensagens de erro informativas
- [ ] Separação clara de responsabilidades (Clean Code / Single Responsibility)
- [ ] Aderência estrita aos contratos de API e modelos definidos na Arquitetura
