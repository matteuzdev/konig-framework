# Checklist do Gate de Produto (PRD Gate)

Critérios obrigatórios para aprovação de PRDs no KONIG Framework:

- [ ] Objetivo do produto claramente articulado com métricas de sucesso (KPIs)
- [ ] Topologia de Marca definida (DNA da marca, arquétipo comercial, tom de voz e proposta única de valor)
- [ ] Demografia e contexto de uso do usuário real caracterizados para orientação de UI/UX e Engenharia
- [ ] Escopo delimitado com distinção clara entre In Scope e Out of Scope
- [ ] Requisitos Funcionais (RF) com identificadores únicos e rastreáveis
- [ ] Requisitos Não Funcionais (RNF) com parâmetros mensuráveis (latência, concorrência, segurança)
- [ ] Critérios de aceite especificados para cada funcionalidade (Given/When/Then)
- [ ] Ausência de ambiguidades técnicas, jargões vagos ou termos subjetivos não quantificados
