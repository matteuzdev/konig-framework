# Checklist do Gate de Homologação QA (QA Gate)

Critérios obrigatórios para liberação de release por Elena:

- [ ] Cobertura de testes unitários e de integração implementada
- [ ] Presença de asserções inequívocas em todos os casos de teste (assert / expect)
- [ ] Pelo menos 2 cenários de edge cases validados (ex: payload nulo, timeout, valores negativos)
- [ ] Todos os critérios de aceite do PRD confrontados e aprovados
- [ ] Emissão de parecer formal de homologação assinado pela Staff QA Engineer
