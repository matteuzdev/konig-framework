# Checklist do Gate de UI/UX Pro-Max (Anti-Generic Gate)

Critérios obrigatórios para blindagem contra designs simplórios ou amadores:

- [ ] Tipografia refinada utilizando fontes contemporâneas (Google Fonts / Inter / Outfit) com escala modular
- [ ] Paleta de cores harmoniosa em HSL com Dark Mode nativo e gradientes sutis
- [ ] Efeito de profundidade visual (Glassmorphism, sombras dinâmicas, backdrop-blur)
- [ ] Estados de micro-interação definidos para botões, cards e inputs (hover, active, loading)
- [ ] Conformidade de acessibilidade com contraste WCAG AAA em todos os elementos de texto
- [ ] Layout responsivo mobile-first com breakpoints fluidos
- [ ] ZERO traços de mediocridade visual ou declarações de "design básico/simples"
