# Checklist do Gate de UI/UX Pro-Max (Brand-Adaptive & Anti-Generic Gate)

Critérios obrigatórios para blindagem estética, alinhamento de marca e usabilidade de elite:

- [ ] Alinhamento estrito com o DNA de Marca e Arquétipo Comercial especificado no PRD
- [ ] Escolha tipográfica intencional (Display + Body) coerente com a voz da marca e com escala modular proporcional
- [ ] Paleta semântica em HSL/CSS Variables com tokens de superfície (Surface, Elevation, Text, Muted, Accent) calibrados para o caso de uso (Light, Dark ou High-Contrast justificados)
- [ ] Profundidade e tratamento visual condizentes com a marca (elevações, bordas, sombras refinadas ou flat design autêntico, sem efeitos gratuitos)
- [ ] Estados de micro-interação definidos para componentes interativos (hover, active, focus-visible, disabled, loading)
- [ ] Conformidade de acessibilidade com contraste WCAG AAA/AA em todos os elementos de texto e alvos de clique ergonômicos
- [ ] Layout responsivo mobile-first com densidade de informação ajustada ao contexto de uso do usuário real
- [ ] ZERO traços de mediocridade visual, cópia cega de templates da moda ou declarações de "design básico/simples"
