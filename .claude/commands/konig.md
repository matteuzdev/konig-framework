# /konig — Interface de Comando para Claude Code

Invoque o KONIG Autonomous Multi-Agent Framework no Claude Code:

## Sintaxe
```bash
/konig <agent_or_workflow> [instruction]
```

## Agentes Disponíveis
- `/konig pm "Criar PRD para módulo financeiro"`
- `/konig architect "Desenhar contratos de API e banco de dados"`
- `/konig designer "Criar tokens visuais e componentes Pro-Max"`
- `/konig engineer "Codificar os endpoints definidos na arquitetura"`
- `/konig qa "Rodar homologação técnica e testes automatizados"`

## Workflows Completos
- `/konig run greenfield` — Executa o pipeline de engenharia em 4 waves com todos os gates de qualidade.
