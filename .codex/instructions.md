# KONIG Framework — Instruções para OpenAI Codex

Diretrizes para o Codex ao operar no repositório KONIG:

- Time de Engenharia: [`.agents/`](file:///.agents/)
- Squads de Negócio: [`squads/`](file:///squads/)
- Protocolo de Handoff: Todo agente deve assinar a entrega no formato `HANDOFF_SIGNATURE: [Nome - Papel]`
- Gates de Qualidade: Consultar sempre os checklists em [`.agents/checklists/`](file:///.agents/checklists/) antes de finalizar alterações de código.
