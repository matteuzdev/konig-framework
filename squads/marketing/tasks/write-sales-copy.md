# Task: Redação de Copy de Vendas de Alta Conversão

```yaml
task:
  id: write-sales-copy
  title: Criação de Copy para Landing Page e Anúncios
  assigned_agent: copywriter
  depends_on:
    - define-market-strategy
  required_gates:
    - copywriting-checklist
  estimated_complexity: HIGH
  output_artifact: sales_copy.md
```

## 1. Objetivo
Produzir uma copy hipnótica e persuasiva estruturada no modelo PAS/AIDA para a página de captura/vendas.

## 2. Passos de Execução
1. Escrever 5 variações de Headline com ganchos magnéticos.
2. Desenvolver a seção de introdução atacando a dor latente do cliente.
3. Apresentar o mecanismo único da nossa solução.
4. Elaborar a oferta irresistível (garantia condicional, bônus e escassez real).
5. Escrever a quebra de objeções frequentes (FAQ Persuasivo).
6. Submeter ao Checklist de Copywriting.
